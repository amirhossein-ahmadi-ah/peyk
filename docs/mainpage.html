async-first

کاملاً async/await؛ چند پیام همزمان بدون بلاک شدن.

@bot.command("a")
async def a(message):
    await message.answer("A")

@bot.command("b")
async def b(message):
    await message.answer("B")

# messages are handled concurrently

    await bot.send(...)

    await retry(e)

  • انتخاب یک‌باره‌ی platform

    platform= هنگام ساخت Bot مشخص می‌شود؛ هندلر، فیلتر و کیبورد مستقل از پلتفرم می‌مانند.

  • اشیای neutral با .raw

    پیام‌ها یکسان‌سازی شده‌اند؛ شیء اصلی پلتفرم از .raw در دسترس است.

  • افت توانایی آگاهانه
